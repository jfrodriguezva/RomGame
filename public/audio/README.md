# Efectos de sonido

Coloca aquí archivos `.mp3` con estos nombres exactos para que el juego los reproduzca automáticamente:

```
/public/audio/effects/correct.mp3
/public/audio/effects/wrong.mp3
/public/audio/effects/win.mp3
/public/audio/effects/click.mp3
/public/audio/effects/star.mp3
```

Si no los agregas, el juego funciona igual (simplemente no suena nada en esos momentos).
