# Cómo agregar tus imágenes

Coloca aquí tus propias imágenes (no se incluye ningún personaje con derechos de autor).

Estructura sugerida:

```
/public/images/princesas/1.png, 2.png, 3.png ...
/public/images/toystory/1.png, 2.png, 3.png ...
/public/images/mario/1.png, 2.png, 3.png ...
/public/images/minions/1.png, 2.png, 3.png ...
/public/images/animales/1.png, 2.png, 3.png ...
```

Puedes agregar cualquier otra carpeta con el nombre que quieras (ej. `/public/images/frozen/`) — solo dime el nombre de la carpeta y cuántas imágenes tiene, y actualizo `data/assets.ts` para que el juego las use en lugar de los emojis de marcador de posición.

Formatos recomendados: `.png` o `.jpg`, cuadradas (1:1), idealmente 512x512px o más.
